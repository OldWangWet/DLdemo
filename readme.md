# 机器学习和深度学习练习

此项目用于机器学习和深度学习练习，具体代码和说明请查看各个子文件夹中的 `readme.md`。

## 后续期望

每个算法目录包含 `main.py`、`readme.md` 和以下三个文件夹，由浅入深逐步学习。`main.py` 使用 sklearn 演示算法，`readme.md` 说明算法原理、公式和示例；三个阶段逐步手动实现，并与 sklearn 对照验证。

1. **`basic/`：** 针对 `main.py` 使用的数据集，依据 `readme.md` 的公式实现算法，优先保证原理清晰、代码简洁。仅采用最小限度的必要优化，或该算法在实际应用中普遍采用的基础优化，例如对数计算、平滑和必要的数组运算。同时提供最小可用接口和基本输入检查，保证示例正确运行。
2. **`optimized/`：** 参考 sklearn 源码，在基础实现上进行系统的算法优化和数学优化，说明优化的依据、收益及适用条件，并验证优化前后的结果。
3. **`sklearn_impl/`：** 完整复现 sklearn 的算法实现和接口行为，包括 CPU、内存等资源优化，规范参数、输入校验、输出和异常处理，并按算法需要支持稀疏数据、样本权重、增量训练等能力。
