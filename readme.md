# 机器学习和深度学习练习

此项目用于机器学习和深度学习练习，具体算法、公式和实现说明见各算法目录中的 `readme.md`。
| 文件夹 | 对应算法 |
|---|---|
| KNN | K临近算法 |
| NB | 朴素贝叶斯 |
## 目录组织与共同约束

每个算法目录包含三个相互独立的实现方向，分别用于学习公式、计算方法和源码中的主要模型能力。各目录按需建设，不要求依次完成，也不要求代码量、速度或准确率依次提高。

```text
算法目录/
├── main.py          # 使用 sklearn 演示算法与数据集
├── readme.md        # 算法原理、公式和手算示例
├── basic/           # 清晰、最小可用的公式实现
├── optimized/       # 算法与数学计算的改进
└── sklearn_impl/    # 按 sklearn 源码实现模型及主要能力
```
